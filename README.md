# Mortgage Repayment Calculator

A responsive mortgage repayment calculator built with HTML, CSS and JavaScript. The application validates user input and calculates estimated monthly and total repayments.

## Live Demo

https://mortgage-calculator-kappa-one.vercel.app

## Features

- Calculate monthly mortgage repayments
- Calculate total repayment amount
- Supports repayment and interest-only options
- Form validation and user feedback
- Keyboard-friendly interactions
- Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vercel

## What I Practiced

This project helped me improve my understanding of form handling, input validation, conditional logic, mathematical calculations, DOM manipulation and responsive UI development.

## Run Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Start it with a local development server.
4. Open the local URL in your browser.
